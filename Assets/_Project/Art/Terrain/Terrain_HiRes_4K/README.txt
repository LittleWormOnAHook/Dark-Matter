Io Moon Surface - 4K CC0 replacement sets
============================================

Created by the Genesis PCG Rock Creation tool on 2026-10-02 (ET). The original 2K Io sets in ../SetNN_* are untouched (legacy).
Layout: HiRes_4K/<Subset>/<SetName>/Io4K_SetNN_<SetName>_{Color,Normal,MaskHDRP,Height}
  Color    : sRGB, recoloured toward the subset's original palette (mean linear albedo matched to the legacy Io colour map)
  Normal   : OpenGL (+Y) tangent-space normal, as shipped by the source
  MaskHDRP : linear; R metallic 0, G ambient occlusion, B height (detail-mask slot), A smoothness = 1 - source roughness
  Height   : linear 16-bit, normalised 0.5-99.5 percentile
All sources are seamless/tileable and procedural (Substance-generated; ambientCG "PBRProcedural", TextureCan with SBSAR source).
