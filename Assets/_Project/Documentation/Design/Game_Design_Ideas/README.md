1. Fold locks into GDD Appendix or the relevant Design doc (e.g. `Io_Underground_Architecture_Plan.md`).
2. Add milestone tickets under `Io_World_Content_Milestone_Tickets.md`.
3. Move status from **Idea** → **Design investigation** or **Locked**.
4. Keep this file as a pointer; do not delete history from the idea doc without explicit approval.
