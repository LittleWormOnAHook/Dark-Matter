When to pick which

Pick V1 if Dark Matter: Genesis should feel like cosmic survival horror with Io as the true boss and silence/frequency language as signature.

Pick V2 if the marketing pillar is colony hope, Building Control Panels, weather-as-schedule, and Phase 5 legacy.

Pick V3 if systemic drama should come from people (factions, Compact votes) more than the moon itself.

Pick V4 if the lead should be a freelance terraform surveyor with two old-friend specialists, Mars stranding backstory, Kairos ledger mystery, and Crimson Desert–like contract-board spectacle — terraform viability + missing expeditions drive the mission, not colony hope (V2) or parliamentary politics (V3).

Recommendation (default spine — user will still compare / change / pick)

Default spine: V2 Colony Horizon for GDD emotional fit and shipped Building Control / storm-shelter fantasy.

Steal from V1: Still Hunter / Silence / Resonance Shelf puzzle language for B3–B7 horror texture.
Steal from V3: Claim Barrier territory grammar + visitor cadence for faction boards.
Steal from V4: Freelancer player fantasy, Kairos prologue naming beat, contract board UX, old-friend starter trio, siege/escort setpieces — even if V2 remains narrative spine.

Do not ship all four AI truths in one build — lock one package spine and one Kairos truth variant.
