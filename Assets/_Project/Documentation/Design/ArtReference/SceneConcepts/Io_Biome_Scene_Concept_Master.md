# Io biome scene concepts — 10 shots per area

**Scope:** One set of **10 environmental frames per surface biome (B1–B7)** on the main map. Same shot **roles** every time; **props and ruins** change per biome. Style: **HDRP in-game+** (Io haze, aged pioneer gear, robots, optional Kade in **one** shot per biome).

**Not included here:** separate POI folders (`Meridian6/`, `AshVeinRest/`) remain as **named drill/camp** deep-dives inside B1/B4; use biomes for region-wide greybox.

## Ten shot roles (repeat per biome)

| # | Role | Build use |
|---|------|-----------|
| 01 | Establishing wide — biome landmark + major wreck | Region identity, horizon |
| 02 | Shelter/hab breach — interior belongings | Environmental story |
| 03 | Dead transport + cable/spool | Scale, pathing |
| 04 | Beacon or relay + powered-down robot | Interact POI |
| 05 | Industrial close-up (biome hazard hardware) | Prop kit |
| 06 | Robot/android group (mixed age, frozen/dead) | Machine presence |
| 07 | Survey stakes / route into distance | Traversal read |
| 08 | Cache/locker/stash small props | Loot rhythm |
| 09 | Kade third-person (scanner or approach) | Player fantasy |
| 10 | Wildlife telegraph (dusk or haze) | Threat ambient |
